# Discovering Scientific Concept Relationships Through Graph-of-Words & RAG

An experimental study investigating whether graph-based representations of scientific literature improve the retrieval of evidence compared with conventional dense retrieval methods, evaluated on the AllenAI SciFact benchmark.

---

## 🔬 Research Question
> **Can graph-based representations (Graph-of-Words) of scientific literature improve the retrieval of relevant scientific evidence compared with conventional dense retrieval methods?**
