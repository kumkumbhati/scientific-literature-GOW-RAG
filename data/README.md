# Data Source & Acquisition

This project uses the **SciFact** dataset developed by the Allen Institute for AI (AllenAI):
- Corpus: `allenai/scifact` (`corpus` split)
- Claims: `allenai/scifact` (`claims` split)

Datasets are loaded programmatically via Hugging Face's `datasets` library and are not tracked directly in version control to ensure lightweight, reproducible repository maintenance.
